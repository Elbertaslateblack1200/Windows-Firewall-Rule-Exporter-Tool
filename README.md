## ❓ Frequently Asked Questions

### Is this tool free?

Yes, completely free. No hidden costs, no premium version, no subscription.

### Will this work on my Windows version?

The tool is designed for modern Windows systems. It works on Windows 10 and Windows 11. For older versions, compatibility may vary, but most users on current systems will have no issues.

### Do I need to be an administrator?

For backing up and exporting, no special permissions are needed. For restoring rules, Windows may ask for administrator approval – this is normal and required by Windows itself.

### Can I edit the exported files?

Absolutely. CSV files open in Excel or any spreadsheet program. XML files open in any text editor. You can modify, review, or share them however you like.

### What if I lose my backup file?

Unfortunately, if you lose the backup file, you can't recover those specific rules. That's why it's recommended to store backups in multiple locations (e.g., cloud storage + external drive).

### How long does backup/restore take?

Usually just a few seconds. Even with hundreds of rules, the process is nearly instant.
